# ScoreDeck CS 2.14.3 · 紧凑导播栏

## 窗口交互修复
移除上一版残留的 focusable:false。使用正常 Windows 原生边框和标题栏，显式启用 focusable、movable、resizable、thickFrame，关闭鼠标穿透，保留置顶。

- 拖动最上方 Windows 标题栏移动窗口；拖动四边或四角调整大小。
- 默认高度从 380 降至 220 像素，最低高度从 340 降至 200；最低宽度 800。高度包含原生边框，实际内容区随 Windows DPI/标题栏大小略有变化。
- 首次升级自动将旧版缓存高度调整到 220，之后保存手动尺寸。右上角“收紧”随时恢复 220。
- 点击导播窗口会获得正常焦点；操作后点击游戏可继续控制游戏。建议游戏使用无边框窗口模式。
- 标题栏和右上角均可关闭窗口，任务栏也可找回导播窗口。

## 减少装饰
去除 ScoreDeck Logo、品牌行、VoiceBridge 英文标题、道具装饰图标、重复区域标题、状态胶囊、大圆角和大块留白。道具按钮改单行名称与有效数量；机位仍按 GSI 显示中文按钮。
两队音频仍在右侧上下分栏，改成紧凑的文字片段和预听/推送按钮。字体与控件随窗口缩放。

保留 2.14.2 的排名规则、返回选手与平滑道具追踪逻辑。

## 启动
先彻底退出旧版（包括托盘/旧主窗口），完整解压后运行本包 ScoreDeck CS.exe。主程序版本应显示 2.14.3。

## 验证范围
原生窗口创建路径的模拟 Electron 测试确认了焦点、移动、拉伸、最小尺寸、鼠标交互、旧尺寸迁移、手动尺寸恢复与“收紧”。真实浏览器测试了 800×161、1100×181、1366×200、1920×240 内容区，六机位与双队音频无控件越界，字号与卡片随尺寸缩放。排名切换和 OBS 同步回归通过。

测试环境不具备真实 Windows 桌面，不能把配置测试等同于实机拖拽测试。窗口仍需 Windows 本机验收。
