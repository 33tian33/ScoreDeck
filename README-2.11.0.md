# ScoreDeck CS 2.11.0

新增「中场休息」独立控制页与 OBS 输出，采用已确认的深蓝 / 亮黄版式。完整保留 2.10.0 的 Replay 0.2.1、VoiceBridge 0.6.3 与 RadarHUD 0.3.11 页面。

## 使用

1. 完整解压 Windows 便携包，运行 `ScoreDeck CS.exe`。
2. 进入侧栏「中场休息」。默认时长 60 秒，左侧 Replay 半场精选、右侧 RadarHUD 半场回放。
3. 设置后点击「保存设置」；开始 / 继续、暂停、重置控制倒计时。到零保留画面，默认显示「即将继续」。
4. 点击本页「复制 OBS 地址」，添加 1920 × 1080 浏览器源。默认本机地址 `http://127.0.0.1:17890/output/halftime`；实际地址随主端口变化。此输出独立于原 `/output/live`，在 OBS 切换场景使用。
5. 原图左上角 SCOREDECK 位置为轮次名称，默认读取当前主赛的轮次；关闭自动读取后可手填。

## 可替换内容

- 左、右展示位分别选 Replay 半场精选、RadarHUD 半场回放、ScoreDeck 内置输出、图片、视频、自定义网页或留空，支持左右互换。
- 内置输出包括小组聚焦、积分、第三名榜、对阵前瞻、赛程、淘汰赛聚焦、赛后 MVP、未来赛程、入场动画、倒计时。
- 展示位可设置完整显示 / 裁切 / 拉伸、标签、音频静音、循环与播放速度。外部网页的播放和声音由其自身控制。
- 标题、轮次、结束文字、队名、队标、地图名、比分、背景图片、颜色、字号倍率、区域比例与间距均可配置；各信息元素提供显隐选项。
- 图片支持 PNG / JPG / WebP（8 MiB），视频支持 MP4 / WebM（256 MiB）。导入素材随赛事归档保存，不依赖原文件位置。

## 半场数据

- 比分来源：手动；所选比赛的指定地图小分；RadarHUD GSI 快照。不会将 BO 总比分当成地图小分。
- GSI 模式先设置截取时左队的 CT / T 阵营，再点「截取 GSI 比分」，或在开始中场时自动截取。快照固定，不随下半场换边颠倒。队名、队标从所选比赛 / 队伍读取。
- Replay：先在原 Replay 页面启动服务并整理「半场精选」。本展示位按该列表播放，使用独立播放时钟，不抢占原 Replay 输出的播放确认通道。原 Replay 输出中的整屏转场不叠加到中场画面。
- RadarHUD：直接使用软件内置 GSI 与半场轨迹，可选择上 / 下半场、楼层、轨迹保留时间、选手位置。中场回放与原 RadarHUD 输出设置独立；回放方式仍为原 RadarHUD 的各回合同轴轨迹回放。
- 倒计时与媒体时钟保存于服务器：刷新浏览器不重新计时；开始带动媒体，暂停同时暂停媒体；也可独立暂停 / 重播媒体。修改时长后点重置，避免改设置时重启正在播出的倒计时。
- 控制页预览视频始终静音。自定义网页只在独立输出加载，防止预览抢占第三方网页播放控制或重复发声。第三方网页须允许嵌入。

## 升级与数据

退出旧版后，将旧目录的 `ScoreDeck CS Portable Data` 复制到新目录同名位置，保留赛事及 Replay / VoiceBridge 配置。不要同时运行新旧版。默认包不包含用户数据。

中场设置存于 `broadcast-state.json` 的 `halftime` 字段，与赛事 JSON / 完整素材归档一起导入导出。既有存档自动补全中场默认值。
