# ScoreDeck CS 2.14.1 · 地图机位

在现有悬浮导播控制栏内加入用户选定的 8 张地图、36 个中文机位按钮。完整解压 Windows 包，运行 `ScoreDeck CS.exe`，打开左下角“导播控制栏”。

## 使用

1. 沿用 RadarHUD 的本机 CS2 GSI 配置，并在悬浮栏连接 CS2。
2. 软件根据 GSI 的当前地图自动显示对应机位：Dust2 5 个、Mirage 3 个、Inferno 5 个、Nuke 5 个、Ancient 4 个、Anubis 6 个、Overpass 4 个、Cache 4 个。
3. 点击中文机位按钮，游戏切换到对应固定观战视角。按钮提示保留用户选择的原始编号；绿色标记表示最近发送的机位，实际画面以 CS2 为准。
4. 切换固定机位会先取消正在运行的道具追踪并清除待发跟随命令。原观战选手仍有效时，可点击“停止 / 返回选手”。
5. 换图后自动更新按钮；未选择的地图、主菜单及 GSI 超过 3 秒未更新时隐藏机位。控制连接未通过回显验证时，机位按钮不可点击。暂停 Demo／冻结时间只要 GSI 心跳保持连接即可操作。

控制栏继续在屏幕底部置顶、不抢游戏焦点，默认高度由 340 调整为 420 像素，机位采用三列布局。语音两行、X 光、游戏 UI 与道具追踪继续使用原有连接和流程。

固定机位直接使用已选坐标，不依赖 HLAE，不自动播放运镜。Cache 的四个机位来自旧版配置，保留原坐标供实机预览。来源、完整编号和许可见 `radarhud/CAMERA-PRESETS-SOURCES.md`。

## 更新与数据

退出旧程序后，将旧目录的 `ScoreDeck CS Portable Data` 文件夹复制到新版目录，或者使用软件的完整包导入功能恢复设置与素材。新版继续使用同一数据格式，不包含用户比赛数据或录音缓存。

## 开发

`npm start` 启动服务；`npm test` 运行回归。`scripts/qa-camera-presets.cjs` 使用 Playwright、模拟 GSI 与 TCP 控制端测试完整链路。可通过 `CHROME_EXECUTABLE` 指定测试浏览器。
