# ScoreDeck CS 2.11.1 — GSI 自动中场

## OBS 一次设置

进入「中场休息」页面，点击「复制自动中场 OBS 地址」。在 OBS 的游戏场景添加浏览器源，设为 **1920 × 1080**，放在游戏捕获上方。

默认地址：`http://127.0.0.1:17890/output/halftime-auto`。若更改主端口，请以页面复制的地址为准。

- 平时透明，不遮挡游戏。
- 内置 RadarHUD 收到新鲜的 GSI 中场信号后，自动显示中场页面，按设定时长开始倒计时，并开始两个展示位的播放。
- 下半场进入冻结时间 / 游戏恢复后自动隐藏，卸载媒体并停止该输出的声音。
- 到零保留「即将继续」，不会仅因倒计时结束而提前退场。

已有 `/output/live` 主输出也会自动切到中场；恢复游戏后返回切入前的展示页。若切入前是入场动画，则返回前瞻。**自动透明输出与主输出选用一种，不要在同一 OBS 场景同时叠加这两个输出。**

原 `/output/halftime` 是始终显示的固定输出；之前若添加了这个地址，要改为 `/output/halftime-auto` 才能自动显隐。

本实现通过浏览器源内部自动切换画面，不需要 OBS WebSocket，也不修改 OBS 场景集合。OBS 必须已添加并启用对应浏览器源。

## 开关与手动操作

「中场休息」中新增并默认开启：

- GSI 检测中场后自动播出。
- 下半场恢复后自动退场。
- 自动截取 GSI 半场比分（沿用已设置的左队 CT / T 对应关系）。

可手动「立即播出中场」或「结束中场播出」，也可在直播控制中切到其他页面。手动切走后，同一中场的重复数据不会抢回节目；如需重播请手动播出。

沿用原 GSI 一键配置，无需另装游戏插件。GSI 必须来自正在观战的 CS2，并持续提供 map、round、phase_countdowns；在 RadarHUD 页面确认连接。

## 触发规则

检测明确的 `phase_countdowns.phase = halftime` 或 `map.phase = intermission`；普通回合结束和战术 / 技术暂停不触发。数据需为实时 GSI 且接收时间不超过 10 秒；旧缓存不能触发。每个中场只触发一次，重复数据、输出刷新和服务重启不会重新启动该中场倒计时。新地图 / 热身 / 新比赛前几回合解除上一场的去重记录。

比分默认在自动触发时截取快照，避免换边翻转。自动比分开关可关闭，保留原来选择的手动 / 地图比分。Replay 服务需提前启动并选择半场精选。

运行状态存于 `ScoreDeck CS Portable Data/halftime-auto-state.json`；赛事归档保存开关和版式，不复制已触发的运行记录。
