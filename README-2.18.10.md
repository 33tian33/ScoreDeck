# ScoreDeck CS 2.18.10

发布日期：2026-10-06。Windows x64 便携版。

- 半场 / 全场精选支持独立 OBS 场景：素材和输出页就绪后自动切入。
- 半场精选播完，或第 13 回合正式进行且剩余时间到达 1:50 时，返回切入前的 OBS 场景。
- 全场精选播完后返回指定的直播控制场景；加载下一张地图不会提前结束当前片单。
- 播出会话固定片单、播放一遍；支持人工切场接管、断线返回重试和重启恢复。
- 修复“复制自动中场 OBS 地址”和编辑器复制按钮缺少 `?obs=1`；复制后显示完整地址，脚本地址加入版本号。
- 栏目底部增加 OBS 连接设置、读取场景、试播、无密码连接支持及完整操作说明。空片单与输出页未就绪分别显示具体原因。
- 包含当前 Replay 0.2.6 集成更新和 RadarHUD 道具轨迹修复。

## 安装与使用

完整解压 ZIP 后运行 `ScoreDeck CS.exe`，不要只取出 EXE。退出旧程序后，可将旧目录中的 `ScoreDeck CS Portable Data` 复制到新版目录以保留数据。

进入“半场 / 全场精选”栏目最下方，按 OBS 配置步骤创建精选场景和直播控制场景。复制的精选源地址形如 `http://127.0.0.1:17890/output/halftime-auto?obs=1`，端口以程序实际地址为准。OBS 关闭身份认证时，勾选“清除已保存密码”后保存。

Replay 对应片单至少需要一段可播放素材；空片单不会切换 OBS。全场触发沿用当前地图结束信号，不是等待整个 BO 系列赛结束。

配套 Linux 录制端应使用 Replay 0.2.6，中继协议不变。
