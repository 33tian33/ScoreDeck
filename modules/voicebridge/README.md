# VoiceBridge 0.6.3 · Audio-in 导播端延迟

导播控制新增「导播端延迟（秒）」：填写后点击「保存延迟」，默认 0。实际播出时间为点击推送时间与语音起点加延迟两者的较晚值。修剪片段使用修剪起点；未修剪片段使用语音起点（不含自动预留静音）。等待时可点击「取消等待」或 Esc；刷新控制台不会取消，重启服务或新建会话会取消。修改设置仅影响新推送，保存后重启仍保留。到点前 OBS 不显示标签、不播放音频；到点后正常加载音频并同步显示标签，实际加载可能略晚。每次仅允许一个等待或播出任务。


在导播台顶部「API 配置」中，先保存**北京地域**阿里云 API Key、工作空间 ID，以及 `paraformer-realtime-v2` 模型，然后点击「创建并启用 CS2 热词表」。成功后界面自动填入并保存 `vocabulary_id`；点击「重启服务并应用」，后续新识别任务即使用热词。重复点击会复用这份预设；此程序创建的旧版预设才会被后续更新覆盖，不会修改手填的其他热词表。已录制片段不会自动重转写。

词表源文件：`data/cs2-hotwords-v1.json`，七张现役地图为 Mirage、Inferno、Nuke、Ancient、Anubis、Dust II 和 Cache，另有通用报点与游戏术语；总计 324 条去重热词。2026 年 7 月 Cache 替换 Overpass。建议用本队实战语音复核别名和误识别，尤其是常用普通词。热词只提升识别概率，不会强制替换转写结果；效果须通过真实语音测量。

创建热词表需要工作空间专属接口；只填 `.env` 中的热词 ID 时可继续原有方式运行。解压到新目录升级时，复制原目录 `.env`、`api-settings.json`、`hotwords-preset.json`（若存在）、`team-names.json` 与 `desktop-settings.json`；如需延续默认缓存会话，再复制 `runtime`。不要公开包含密钥的 `api-settings.json`。

# VoiceBridge 0.6.0 · Windows x64 国内接口便携版

用于两个 TeamSpeak 频道的逐人录音、语音转写、情绪片段筛选与 OBS 手动播出。

## 启动与升级

1. 将完整压缩包解压到新目录，运行 `Start-VoiceBridge.cmd`。内置 Node，无需 npm 或编译。
2. 首次运行在打开的配置文件内填写自己的阿里云北京地域 `DASHSCOPE_API_KEY`；`DEEPSEEK_API_KEY` 用于语义筛选，不填写则使用关键词初筛。
3. 从0.5.3升级：退出旧服务，将旧 `.env`、`team-names.json` 和 `desktop-settings.json`（存在时）复制到新目录。要保留默认缓存中的会话，也须复制完整 `runtime` 目录；自定义缓存路径继续有效。不要同时运行新旧服务。
4. 原生插件仍为0.5.0，0.5.x用户无需更新DLL。旧0.4版本须用GUI安装新插件，退出TS3后安装，重启并在TS3插件管理中启用。
5. 双队监听需在同一TS3客户端先建立两个连接标签页，再在GUI分别进入频道、绑定两队。每个标签页仍只监听一个频道。导播使用额外账号，插件不采集导播自身麦克风。

## 0.6.0 更新

### 边采集边上传

阿里云默认启用流式上传：每人通过发声检测后即开始上传，不再等4秒完整片段采完才发送。每个有界语音窗口仍沿用绝对样本时间轴，窗口结束后收取最终结果，临时识别显示在“导播控制”中，不作为分类证据。默认最多10个流式窗口；满额时该语音保留为分段补识别，原始全队录音不受影响。

连接错误保留WAV任务，并按错误类型重试或标为失败。最终失败不阻塞后续片段定稿；点击“重试失败识别”会在后台补识别，不撤回已审核、已定稿片段。超过旧200条队列上限后不再主动丢弃任务，完成窗口的任务保存在磁盘，重启可恢复。缓存空间仍需监控：磁盘写入失败或进程在活动窗口落盘前突然终止不保证自动恢复该窗口。

可选配置（修改后重启）：

```ini
ASR_STREAMING=true
ASR_STREAM_CONCURRENCY=10
ASR_CONCURRENCY=4
ASR_CHUNK_SECONDS=4
ASR_VOCABULARY_ID=
```

`ASR_CONCURRENCY`控制分段识别任务；`ASR_STREAM_CONCURRENCY`控制实时任务准入。可降低并发适配账号限流。设置 `ASR_STREAMING=false` 回到分段识别。热词ID须为自己已创建、匹配模型的Paraformer词表。实际延迟、费用和识别质量需以真实环境测量为准。

### 修剪、审核与片段状态

候选卡片可“修剪 / 审核”：用会话秒数指定起止，前后扩展1秒，修改标题与分类，保存或保存并预听。结束时间不得超过实际录音，单片段最多120秒。保存后预听与OBS使用同一份全队混音；原始逐人录音不修改。类别为内讧时使用“氛围对了”标签，其余使用标准标签。

支持待播、收藏、忽略和已播筛选，OBS确认声音开始后记录播放次数，加载失败不会记为已播。可暂停左右两栏列表更新，阅读时避免新卡片挤动；恢复后仍按最新内容置顶。Esc停止预听与正式播出。

### 显式绑定OBS输出

OBS浏览器源：`http://127.0.0.1:8787/overlay?output=program`，1920×1080，60fps。旧 `/overlay` 地址等价于 `program`。

打开浏览器源后，在导播台“正式输出”选择 `program` 并点击“绑定此输出”。绑定重启后保留，未绑定不播出。测试页使用 `?output=test`。两个输出使用同名标识、目标离线或已有片段正在播放时，系统拒绝新播出，不会自动发往其他页面。播出目标与片段不可在播放中修改，请先停止。

### TS3静音与监听设备

“自动保持TS3静音”每3秒检查当前活动输出设备中的TS3音频会话，设置重启后保留；找不到会话时显示原因并在之后继续检查。取消勾选只停止强制静音；“取消静音”同时关闭自动保持并恢复TS3声音。其他浏览器和OBS应用音量不受该操作影响。

监听和预听可选择浏览器已授权的输出设备；设备选择依赖浏览器的 `setSinkId` / `selectAudioOutput` 支持。不支持时界面会提示通过Windows混合器指定浏览器输出。指定设备断开时停止监听和预听。即使指定耳机，OBS是否录入这路声音仍取决于OBS自身的音源配置。

## 保留的行为与限制

- 逐人发声检测仍为去直流RMS与底噪阈值检测，并非神经网络VAD。短促欢呼、持续噪声仍可能误判，可调整原有VAD参数。
- 未配置DeepSeek或调用失败时为关键词初筛，所有片段仍由导播手动播出。
- 缓存额度仍是单会话PCM额度，不包含所有历史、识别WAV和生成片段；不会自动清理历史。
- 未加入GSI回合关联、自动高光剪辑或费用账单接口。
- 不含个人密钥或录音。升级前退出旧服务，保留原包及配置可回退。
