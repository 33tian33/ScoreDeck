# 0.6.3

- 增加可持久保存的导播端延迟（秒），支持小数，范围 0–86400。
- 以选中语音起点加延迟计算服务端播出时间；等待倒计时与取消。
- 设置变更不改变已安排的任务；重启或切换会话取消待播。
- OBS 原输出离线、重连或重名时终止待播，避免推错输出。
- 保存录音时间轴的实际时间基准，恢复会话时保留停机期间的时间间隔。旧会话无实际时间基准时按恢复时刻和最后采集位置建立兼容基准。
- Windows 运行时和 TS 插件沿用已打包二进制，本次修改 GUI 与 Node 服务。
