# VoiceBridge 0.6.2 · API 图形配置

1. 双击原有便携启动脚本，打开导播台。
2. 在顶部「API 配置」选择阿里云百炼或 OpenAI / Whisper 兼容接口。
3. 填写对应 API Key，选择或输入模型。阿里云默认使用现有北京接口与 paraformer-realtime-v2；请确保密钥、工作空间和接口属于同一区域。
4. 如需智能分段，填写 DeepSeek API Key 和模型；也可选择「本地规则」。
5. 点击「保存 API 配置」，再点击「重启服务并应用」。手动使用 node/npm 启动时，关闭服务后重新启动。
6. GUI 配置优先于 .env；未保存 GUI 配置时继续兼容原有 .env。

密钥输入框留空代表保留，不会覆盖已有密钥。切换服务商保留两套密钥。
页面不会回传已有密钥；显示按钮仅显示本次输入内容。
配置保存在软件目录 api-settings.json（本机明文），不要把该文件发送给他人。
新版本解压到新目录时，可从旧目录复制自己的 .env 或 api-settings.json；不要覆盖运行中的程序。
重启会暂时中断采集与播出，已有会话按原程序逻辑恢复。

OpenAI 兼容服务必须支持 /audio/transcriptions，并返回带时间码的 segments；模型建议使用 whisper-1。模型输入框允许填写自定义名称，但不代表后端支持任何模型。

## CS2 热词

先保存北京地域工作空间 ID 与阿里云 API Key（模型为 `paraformer-realtime-v2`），然后按「创建并启用 CS2 热词表」。成功后热词表 ID 会自动保存，点击「重启服务并应用」。热词表由本机调用阿里云创建，发布包不包含账号密钥，也不包含预先创建的通用 ID。缺少工作空间 ID 时可在阿里云百炼控制台查询，或手动填入自己已有的、模型匹配的热词表 ID。不要将个人密钥、`api-settings.json` 或录音发给他人。

首版词条见 `data/cs2-hotwords-v1.json`。阿里云对 Paraformer 的单表上限为 500 条；本版 324 条去重词。更新词表预设或更换工作空间后需要重新点击创建并重启。每个账户最多 10 份预编译词表，安装新包时复制 `hotwords-preset.json` 可复用已创建的词表 ID。
