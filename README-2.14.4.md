# ScoreDeck CS 2.14.4 · 释放 23415 端口

当前版本的 RadarHUD / GSI 模块不再监听 23415。

| 用途 | 默认端口 / 地址 |
|---|---|
| RadarHUD 控制台 | http://127.0.0.1:23416/ |
| OBS 雷达浏览器源 | http://127.0.0.1:23416/output |
| CS2 GSI 接收 | http://127.0.0.1:31337/gsi |

上一版占用 23415 的是 RadarHUD 网页服务，GSI 默认已是 31337。新版将网页端口改为 23416，保留现有 GSI 的 31337，避免不必要地改动 CS2 配置。

旧 SCOREDECK_RADAR_PORT / HUD_PORT / --hud-port 若指定 23415，自动映射到 23416；SCOREDECK_GSI_PORT / GSI_PORT / --port 若指定 23415，自动映射到 31337。一键生成的 RadarHUD GSI 配置也不会写入 23415。其他合法自定义端口保留，新端口被占用时报告冲突，不会退回 23415。

关闭旧 ScoreDeck 后完整解压并运行 ScoreDeck CS.exe，确认版本 2.14.4。
已添加到 OBS 的旧雷达浏览器源需把 URL 更新为 http://127.0.0.1:23416/output。主播出和中场输出地址不受本次修改影响。
如果曾手动把本模块的 CS2 GSI 配置改为 23415，请在 RadarHUD 板块重新点击一键配置并重启 CS2。原本使用 31337 的配置无需修改；其他软件的配置不改动。

包含 2.14.3 的紧凑可交互窗口及此前的排名、机位、追踪功能。
