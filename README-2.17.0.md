# ScoreDeck CS 2.17.0 · 队伍管理、中文输入与赛段播出

完整解压 Windows x64 便携包，运行 `ScoreDeck CS.exe`。左侧版本应为 2.17.0。

## 队伍管理

队伍管理改为独立队伍库，取消分组筛选和队伍内的小组设置，可以自由新增、删除、搜索队伍，也支持空队伍库。每队原有的名称、简称、主色、双 Logo、入场与 Clutch 配置、选手资料、头像、位置及首发设置继续保留。具体参赛分组在「赛段与流程」中选择。

删除前提示受影响的赛段和对阵；删除后清理参赛引用及受影响的下游赛果。删除正在参赛的队伍会使赛事返回草稿，需要重新校验并启用；删除未参赛队伍不影响赛事启用状态。旧有队伍资料随升级保留。

## 中文输入

文本输入在输入法组词期间保留本地候选内容，确认文字后才提交保存，避免状态同步打断拼音输入。普通文本短暂延迟保存，移开焦点时立即提交；搜索即时响应。队名、简称、赛段名称及其他受控文本框使用统一处理，入场面板也处理输入法确认事件。内置离线中文字体，避免缺字方框。

## 导播与展示

直播控制按赛段独立保存展示选项，切换赛段时使用该赛段的主对阵。赛前、赛后、MVP、入场以及自动轮播使用同一赛段范围；轮播可指定赛段、页码和主对阵。

- 循环赛积分展示支持每页 1、2、4 个小组，按需选组和分页；保留胜平负、积分、净图与净回合、排名去向。
- 瑞士轮展示战绩、BU 与晋级状态；淘汰赛及自定义赛段展示实际战绩和终结结果，不生成虚构积分。
- 对阵聚焦支持 1、2、4 场、按轮次或手动选场；决赛与季军赛可以同屏，显示选手阵容和冠亚季殿去向。
- 自定义赛程图按实际连线生成，区分胜者与败者路线，显示轮次、BO、比分和出口；大型赛程自动分页，并标明跨页来源与目标。
- 赛程与结果支持全部、未完成、已完成筛选。空赛段显示明确提示。

延续 2.16.0 的模块化对阵、实时保存、全部路径终结校验和启用限制。赛事尚未启用时，主赛事输出保持草稿提示。详细赛制配置参见 `README-2.16.0.md`。

## 升级与源码

关闭旧程序后完整解压新包。升级前可在「归档与恢复」导出 `.sdpack`。不要使用旧版编辑新格式赛事。既有 RadarHUD、VoiceBridge、回放与中场集成继续随包保留。

主要改动：`server/tournament-flow.cjs`（队伍引用与生命周期）、`server/flow-display.cjs`（赛段展示模型）、`ui/text-field.js`（输入法处理）、`ui/flow-display.js`（导播与输出界面）、`dist/assets/flow-display.css`。执行 `npm run build:ui` 重建 UI，`npm test` 运行回归。

验证详情见 `VERIFICATION-2.17.0.md`。尚未在真实 Windows 输入法、CS2/GOTV、OBS 或多人 TeamSpeak 环境进行联动验收。
