# ScoreDeck CS 2.14.0 · 融合导播控制栏

延续 2.13.0 的石墨灰简洁视觉，融入 VoiceBridge 0.6.4-R2 的导播控制流程，并将实时道具镜头放进同一个底部悬浮栏。

## 使用
1. 完整解压 Windows 便携包，运行 ScoreDeck CS.exe。请保留完整目录，不要在压缩包中直接启动。
2. 点击左下角“导播控制栏”，或进入“VoiceBridge 语音”点击“打开导播控制栏”。控制栏在屏幕底部置顶，提供换屏、设置和完整控制台入口。
3. 在 RadarHUD 页面配置本机 CS2 GSI。使用本机 GOTV / Demo；游戏采用无边框窗口模式。
4. CS2 默认启动参数为 -netconport 2121。控制栏“设置”内保存端口并连接；使用 Workshop Tools 时可改为 VConsole，端口和版本须与实际一致。连接通过真实 echo 回显验证，实际镜头效果仍需在游戏里确认。
5. 启动 VoiceBridge，按原流程配置 TS3、ASR 和唯一 OBS 输出。两个队伍的音频分为两行，最新片段在左侧，支持横向滚动、回到最新、耳机预听、推送和取消推送。

## 道具选择
- 闪、烟、雷、火分别选取；只使用最新 GSI 中仍有效的对象。
- 优先当前观战选手最近 2 秒内投出的同类道具。优先使用游戏 lifetime 计算年龄；缺失时使用本机 GSI 首次出现时间。启动或重连时已有且缺少 lifetime 的道具不会被误认为刚投出。
- 最近道具已经消失时，从当前有效的同类道具里选择距离选手最近的目标；按三维距离排序，距离相同优先更新的道具。
- 正在生效的烟雾、正在蔓延的火区继续显示数量并可追踪，不因 effect_time 大于零被排除。消散或熄灭后从候选中移除。
- 燃烧瓶转成新 inferno 实体时，按同投掷者及附近坐标衔接火区，并跟随火焰中心。未能可靠对应时正常结束，不任意切换选手的道具。
- 一次追踪锁定目标；点击停止或目标消失后尝试返回原观战选手。再次点选按最新数据重新找目标。最长单次追踪默认 12 秒，可设置 2–20 秒。
- GSI 过期、控制连接中断或面板心跳丢失时停止追踪；原选手不再存活或缺少观战槽位时不发送随机返回命令。

## 游戏与语音控制
X 光、游戏 UI 和镜头追踪共用同一条 CS2 控制连接；支持 Netcon 文本和 VConsole。游戏 UI 隐藏同时关闭击杀提示，恢复完整 UI 时恢复默认击杀提示设置。状态来自游戏回显，不在点击后直接假定成功。

VoiceBridge 的两队待选列表保留片段身份；鼠标按下后列表刷新不会误推另一片段。预听经本地音频代理，播出沿用原有导播延迟、唯一 OBS 绑定和播放回执；控制栏不另建播出时间线。预听使用系统默认音频输出，请使用耳机。

## 迁移
先退出旧版和新版，再把旧程序目录的 ScoreDeck CS Portable Data 复制到新版目录同名位置；也可使用“归档与恢复”导出、导入完整包。主题、赛程、中场、Replay 和 VoiceBridge 原有设置继续保留。完整包包含新的道具控制设置，沿用排除回放和录音缓存的规则。CS2 控制连接需要显式连接，不在开机后自动操作镜头。
