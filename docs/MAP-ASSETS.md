# 地图卡片素材

9 张卡片：Dust II、Mirage、Inferno、Nuke、Ancient、Anubis、Overpass、Train、Vertigo。

底图为 CS2 游戏地图缩略图，前景为可缩放 SVG 地图名称和渐变。不是新绘制的地图场景。地图图像版权归 Valve Corporation；ScoreDeck 不声称拥有底图版权。制作脚本只将原图嵌入矢量布局，不修改原图。

来源与检索（2026-09-27）：

- CS2 官方地图介绍：https://www.counter-strike.net/cs2
- CS2 depot 图像提取项目：https://github.com/MurkyYT/cs2-map-icons
- 原始图像路径及逐文件 SHA256：`dist/assets/maps/sources.json`
- 重建：`python scripts/build-map-cards.py`（需要网络；常规运行和打包均直接使用已内置资源）

此列表是可选地图库，不能据此推断当前赛事官方地图池。BP 默认七步模板，由导播人工选择本场所使用的七张地图。

卡片预览和当图战绩截图使用测试数据。画面中实际队标仍读取队伍管理中的图片，并不将测试队伍简称替代真实队标资产。
