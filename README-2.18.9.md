# ScoreDeck CS 2.18.9

- 修复导播控制栏在切换窗口、恢复窗口或其他置顶窗口出现后被压住的问题。
- 使用更高的置顶层级；在显示、恢复、失焦、移动和调整大小时重新抬升，并每秒恢复窗口顺序。
- 恢复置顶不会主动获取输入焦点；仍可移动、缩放和点击操作。手动最小化、隐藏及关闭会被尊重，不会自动弹回。
- 再次打开已最小化的导播控制栏，会恢复并重新置顶；关闭后停止定时检查。
- 包含 2.18.8 的中央 Replay 单段回放、独立倍率、默认金色转场和跨组比较器。

完整解压后运行 `ScoreDeck CS.exe`。升级前退出旧程序并备份 `ScoreDeck CS Portable Data`，需要保留数据时复制该目录到新版程序目录。

已验证 Windows 中其他置顶窗口及无边框全屏窗口覆盖后的恢复。真实 CS2 独占全屏、系统安全桌面和其他程序持续强制抢占最上层的场景未作保证。验证记录见 [VERIFICATION-2.18.9.md](VERIFICATION-2.18.9.md)。
