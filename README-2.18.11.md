# ScoreDeck CS 2.18.11

发布日期：2026-10-06。Windows x64 便携版。

- 直播控制新增两个独立的自定义推送面板，支持文字、色块、外部图片和视频。可编辑位置、大小、旋转、透明度、背景、字号、字体、颜色和图层顺序，支持拖动、缩放、复制与隐藏元素。
- 两个面板独立保存，提供预览和推送播出，也可加入输出轮播。独立 OBS 浏览器源路径为 `/output/custom1` 和 `/output/custom2`，主输出仍为 `/output/live`，画布为 1920×1080。
- 默认赛段输出根据当前页的实际内容自动放大，字号与元素同步缩放，增加纵向空间并居中；完整赛程的各轮次分别垂直居中。
- 完整赛程标注日期和时间，在保留晋级连线的前提下，同列比赛按时间排序。赛程与结果列表按日期和时间从早到晚排列。
- 赛程与赛果新增小组筛选、队伍及选手搜索，支持与赛段和完成状态组合使用；可切换时间排序与原始顺序，并可清除每场比赛的日期和时间。
- 未完整设置日期与时间的比赛排在已确定时间的比赛后面，保持原有赛程顺序；同一时间的比赛保持原顺序。
- 延续 2.18.10 的 OBS 精选场景自动切换，以及 Replay 0.2.6 和 RadarHUD 集成。

## 安装与使用

完整解压 ZIP 后运行 `ScoreDeck CS.exe`。升级前退出旧程序，将旧目录中的 `ScoreDeck CS Portable Data` 复制到新版目录以保留赛事和设置。

在“直播控制”选择“自定义推送 1”或“自定义推送 2”，添加文字、色块或导入素材，编辑画布后点击“推送播出”。修改自动保存。支持 PNG、JPG、WebP 图片（单张最大 8 MB）和 MP4、WebM 视频（单个最大 256 MB）；也可输入 HTTP / HTTPS 素材地址。编辑和预览始终静音，正式输出使用视频元素的静音设置。

在“赛程与赛果”使用“小组筛选”“搜索队伍 / 选手”和“排序方式”，点击比赛下方“清除比赛时间”可重置为时间待定。

发布包包含版本对应的源码和 Windows 运行组件，附逐文件 SHA-256 清单与同名 ZIP 校验文件。验证范围见 [验证记录](VERIFICATION-2.18.11.md)。
