# ScoreDeck CS 2.19.0

## 本机模块

Replay 与 VoiceBridge 的完整控制台直接挂载在 ScoreDeck 主窗口中，取消这两个模块的 iframe。组件独立管理样式、网络连接、定时器和音频资源；切换栏目保留编辑内容，重启模块后重新挂载。OBS 透明输出仍使用独立地址。

## 网页赛事同步

打开“归档与恢复”或“设置”中的“网页赛事同步”，点击“预览网站数据”，核对赛事名称及数量后点击“同步到本地”。

- 数据源为 `https://hushang985.online/` 的公开赛事接口。同步队伍、阵容、队标、头像、比赛、BP、逐图赛果和个人战绩、MVP、赛段、积分、比较器、赞助商和赛事设置。
- 原始响应保存在数据目录的 `web-sync/`，同步前本地数据备份保存在 `backups/` 并可在“归档与恢复”中恢复；图片下载到 `media/`，本地使用无需继续依赖图片网址。
- 图片缓存跨同步和重启保留。官网内容哈希地址直接复用经校验的本地文件；普通地址使用 ETag／Last-Modified 条件请求，未变化时不下载正文。丢失或损坏的文件自动补下载，进度分别显示复用和下载数量。
- 同源记录使用稳定编号更新。无关本地记录及网站后来删除的旧记录保留，不自动删除本地内容。
- 网站为同步赛事的权威来源：积分与晋级按网站快照展示，世界杯第三名对位不会被本地其他规则重新计算。网站后续变化需再次点击同步。
- 同步只读取网站，不向网站上传本地更改。网页管理员账号、会话和审计日志不属于公开赛事接口。
- 导入超过四个赞助商时全部保留并可在设置中查看；播出时每八秒切换一组，每组四个。
