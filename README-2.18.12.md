# ScoreDeck CS 2.18.12

发布日期：2026-10-08。Windows x64 便携版，完整解压后运行 ScoreDeck CS.exe。

## 本次更新

- GSI 检测到全场结束后自动录入当图战绩，支持“队名 + 空格 + ID”，保留完整昵称及队伍简称匹配，换边后继续按选手身份追踪。
- 每队仅有一个未知 ID 且首发可唯一确定时，按首发与排除法录入；多个 ID 无法匹配时，对应位置保留空白，并在管理端底部列出 ID、战绩和核对信息。导播当图战绩输出不显示这些提示。
- 手动修改按地图优先保留，后续地图继续自动采集；修复旧赛果窗口覆盖后来采集的其他地图、重新加载把空白战绩变成 0、结束后新局数据改写上一图等问题。
- 验证 BO1 / BO2 / BO3 / BO5 的多图隔离、重复结束数据、换边、保存与重启；拒绝重复地图和无效个人战绩。
- BP 支持格式化文本导入：按本场全名或唯一简称匹配队伍，保留原文 BAN/PICK 顺序和归属，识别系统剩余地图与逐图 CT/T 选边；先解析预览再保存，拒绝队名歧义、重复地图和不完整记录。
- BP 地图选择增加 Cache，并包含对应地图图片。
- 固定机位和道具追踪直接通过 spec_goto 定位，移除前置 spec_mode 6；扩充控制台指令拒绝识别，拒绝后停止追踪。
- 延续自定义推送画布、赛程筛选排序及现有 Replay / RadarHUD / VoiceBridge 组件，Replay 版本为 0.2.6。

## 升级与验证

升级前退出旧程序，保留旧目录中的 ScoreDeck CS Portable Data；需要沿用数据时，将其复制到新版目录。下载 ZIP 与同名 SHA-256 校验文件。

本地完整回归 171 项全部通过，包含原生 Replay 集成测试，无跳过。便携包基于 2.18.11 的运行时重新打包，应用源码对应本次发布提交；包内 BUILD-MANIFEST-2.18.12.json 记录源码提交，PACKAGE-SHA256.json 记录逐文件摘要。验证范围见 [验证记录](VERIFICATION-2.18.12.md)。
