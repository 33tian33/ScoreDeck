# ScoreDeck CS 2.19.4

修复网站赛事同步的超时限制，并增强下载进度显示。

- 网站数据和图片的单次请求超时统一为 **3 分 30 秒（210 秒）**，修复图片等待响应时仍受较短超时限制的问题。
- 保留最多 **8 路并行下载**、缓存复用及自动重试。
- 增加素材处理进度条、百分比和当前处理数量，同时显示复用、下载、重试和失败统计。
- 保留 Replay 0.2.11 及上一版本的其他功能。

下载 Windows x64 便携 ZIP，完整解压后运行 ScoreDeck CS.exe。升级前退出程序，保留原 ScoreDeck CS Portable Data 数据目录。SHA-256 校验文件随包提供。

验证范围见 [2.19.4 验证记录](VERIFICATION-2.19.4.md)。
