# ScoreDeck CS 2.18.8

- 导播控制栏缩小右侧 VoiceBridge，中央显示当前 Replay 会话最新一段可用视频的静态预览。
- 视频下方提供 `0.25`、`0.5`、`1` 倍率选择。选择倍率不会开始播放；点击视频才会通过 Replay 自身浏览器输出播出该片段。
- 倍率仅用于这次单段回放，转场仍为原速；不修改回合、半场、全场回放的倍率或队列。播出中切换按钮只影响下一次点击播出。
- 内置 `Replay-gold.mp4`：Replay 启动时为未配置的进入、退出转场自动导入金色视频，保留已有自定义转场。
- 小组赛新增跨组比较器，可选择各组最终名次进行比较，将比较后的名次连接到后续比赛；支持循环赛、GSL、人数调整及上游结果变化后的下游失效处理。
- 修复队伍自动跟随切换时与后台同步重叠的时序问题，关闭跟随后可立即手动修改队名。

完整解压 Windows 便携 ZIP 后运行 `ScoreDeck CS.exe`。更新前退出旧程序，并备份原目录的 `ScoreDeck CS Portable Data`；需要保留数据时将该目录复制到新版程序目录。

使用中央 Replay 前，先启动 Replay，并在 OBS 中打开 Replay 自身的浏览器输出地址。控制栏不在本地播放预览视频；输出离线、没有素材或已有回放正在播出时，播出按钮不可用。

包含 Replay 0.2.5 的 ScoreDeck 集成版本。Linux 录制端与公网中继沿用 0.2.5 配套要求。验证范围见 [验证记录](VERIFICATION-2.18.8.md)。
