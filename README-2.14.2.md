# ScoreDeck CS 2.14.2

## 小组同分排名
在「赛事设置 → 赛事信息 → 小组同分排名规则」切换；「赛制与排名」也提供同一选项。

- 胜负关系优先：积分 → 同分队相互交手积分 → 总净胜小局 → 总净胜图。
- 净胜小局优先：积分 → 总净胜小局 → 胜负关系 → 总净胜图。首次使用或旧赛事未配置此项时为默认选项。
- 多队同分用交手小积分表，分出部分队伍后，对余下同分队重新比较。尚未全部交手时使用总净胜小局；仍全相同以队名/ID稳定排序。
- 跨组第三名无可比交手，使用积分 → 净胜小局 → 净胜图。瑞士轮仍用原有胜场/BU规则。
- 控制台、小组聚焦、OBS积分榜、小组名次和第三名榜复用相同排名函数；切换会实时更新。设置写入赛事数据及完整包。

## 导播窗口
拖动 Windows 标题栏移动，拖动边缘或四角拉伸。保持置顶，内部按钮、字体、机位和音频卡片按窗口比例缩放。默认位于屏幕下方，双队音频仍在右侧上下排列。
窗口大小与位置自动保存在赛事数据目录，完整包会包含该设置；换屏或显示器变化后限制在可见区域。建议 CS2 使用无边框窗口模式。

## 返回选手
修复旧逻辑的命令顺序和第一人称模式：先 `spec_mode 1`，再按选手名称 `spec_player`。不再把 GSI 的 HUD 编号误当成引擎实体槽位。安全的唯一名称直接选人；重名或不适合命令的名称，以及直接选择后目标不匹配时，通过有限次数的 `spec_next` 和后续 GSI 反馈定位。
返回只在原选手存活且数据有效时进行；换图、断线、新机位会取消待处理返回。界面显示等待确认、当前 GSI 目标或失败信息，不把写入 TCP 当作成功返回的证明。
命令顺序参考：[CS Demo Manager 原生 CS2 选择选手实现](https://github.com/akiver/cs-demo-manager/blob/main/src/node/counter-strike/json-actions-file/json-actions-file-generator.ts)。

## 道具追踪
默认镜头水平后移 220、抬高 120，更新频率 60 次/秒、平滑时间 90ms；导播设置中可调整。旧版默认值自动迁移，自定义距离/高度保留。
使用约 60ms 的位置缓冲补间、最多 80ms 有限预测、按时间计算的位置及朝向平滑、水平转向限速。陡峭上抛时镜头不会因沿三维速度反向后退而落到道具下方；弹地转向时避免立刻翻转。
烟雾和火区仍按有效实体追踪。闪、烟、雷、火以及36个中文固定机位的选取规则保留。

## 使用和验证范围
关闭旧程序，将压缩包完整解压后运行 `ScoreDeck CS.exe`。不要直接在压缩包内运行。迁移赛事可用旧版导出完整包，在新版导入；回放和录音缓存不包含在完整包。

已验证模拟 GSI/TCP 链路、浏览器联动、排名切换、四种窗口尺寸和发布包完整性。当前环境不能运行 Windows CS2/GOTV，原生窗口的实机拖拽、游戏实际返回视角和追踪画面平滑程度仍需实机验收；没有引入 HLAE。
