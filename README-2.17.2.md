# ScoreDeck CS 2.17.2 · 半场精选自动收集

完整解压 Windows x64 便携包，运行 `ScoreDeck CS.exe`，版本应为 2.17.2。

Replay 默认自动把当前比赛、当前地图、当前会话中已生成的 R1—R12 击杀视频加入「半场精选」。顺序固定为回合升序，再按同回合击杀发生时间排序，不受录制或下载完成顺序影响。

仅加入已完成的有效击杀片段。排除重复击杀、道具镜头、第 13 回合以后的片段、旧地图及旧会话。程序启动会补齐已存在的片段，新视频就绪后自动更新；换图或新会话后清理旧精选。

在 Replay 的「OBS 网页输出」中新增「自动收集 R1–R12 击杀到半场精选」，默认勾选。自动模式下精选顺序受保护，不需要逐条点星号。关闭该选项并保存后，可以手动选片、排序、移除；重新开启后恢复自动收集。

ScoreDeck 中场页面直接使用该精选列表，所以 GSI 触发中场后可以按 R1→R12 播放，不必提前手选。仍需启动 Replay 并正常生成击杀回放，RadarHUD 接收 GSI，OBS 添加中场信息里的「自动中场 OBS 地址」。没有成功录制的击杀不会凭空生成视频。

2.17.1 的主赛队名、队标同步和外部设置入口保留，详见 `README-2.17.1.md`。

源码：`modules/replay-source/internal/replay/half_collect.go`；队列在持久化和启动时统一整理。Windows Replay 程序已重新编译。验证详见 `VERIFICATION-2.17.2.md`。
