# ScoreDeck CS 2.19.1

内置 Replay 从 0.2.9 升级至 [上游正式版 0.2.10](https://github.com/33tian33/Project-Replay-in-for-CS2-tournaments/releases/tag/v0.2.10)。

- 录制启动至少提前 0.3 秒；更大的自定义提前量继续保留，连续录制中的切镜间隔独立计算。
- 输出视频的媒体时间或视频帧连续约 3 秒不推进时，清空视频和 Replay 标识、恢复透明并报告异常。
- 拆弹阶段沿用已建立的炸弹倒计时，支持中断及再次拆弹；没有时钟基线时等待有效数据。
- 自动玩家槽位探测分段执行，保留已核验槽位和进度，并为即将开始的录制让出相机。录制调度使用单调时钟。
- 增加 GOTV 接收超时、断流与服务器地址需核对的提示；录制失败原因保留，运行日志保存到 Replay 数据目录并轮转。

保留 ScoreDeck 队伍同步、主窗口原生控制台、手动及按时间精选、默认金色转场和导播栏 0.25 / 0.5 / 1 倍速回放。

Windows 导播端和 Linux Agent 应同时升级至 Replay 0.2.10，保留各自数据目录与配置。新安装包不会替换正在运行的程序；请退出旧程序后使用新包。

来源、合并记录和验证边界见 [Replay 升级记录](modules/replay/UPGRADE-0.2.10.md) 与 [2.19.1 验证记录](VERIFICATION-2.19.1.md)。
