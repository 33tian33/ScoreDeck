# ScoreDeck CS 2.19.2

修复网站资源同步慢、遇到短暂故障后需要反复预览和点击同步的问题。

- 打开“归档与恢复”或“赛事设置”中的“网页赛事同步”，点击一次“开始同步”即可自动读取网站、下载资源并保存赛事。“仅预览网站数据”保留为可选操作。
- 同步在后台执行，切换栏目或刷新页面后自动恢复同一任务的进度显示。重复点击和启动响应丢失后的自动重试不会重复创建任务或备份。
- 资源下载由 6 路增加至 8 路并发。网络中断、超时及 HTTP 408 / 429 / 500 / 502 / 503 / 504 自动退避重试，单次请求最多尝试 3 次。
- 从赛事接口识别官网最终域名，图片直接访问最终地址，避免每张图片都先从裸域跳转到 www；缓存仍统一识别两个域名。
- 图片下载使用独立的 120 秒总时限，等待网站响应头仍限制为 30 秒，避免大图在持续传输时被原来的 30 秒整段时限中断后从头重下。
- 每完成一批资源就保存缓存索引；某张图片最终失败后，其他图片继续处理。修复源站问题后重试时复用已下载内容，普通地址继续通过条件请求检查更新。
- 同步期间切换画面、选择比赛或编辑无关本地记录不会再因为全局版本号变化而取消同步；真正修改了网站将替换的赛事内容时仍会停止覆盖。导播授权交接、归档或恢复状态变化后，旧任务不能提交。
- 页面显示下载、复用、自动重试和失败数量。只有全部资源就绪才保存赛事，保留同步前备份与网站原始快照。

首次同步仍受官网和本机网络带宽影响。持续离线、图片不存在或内容损坏会明确报错并保留已下载资源，不会无限重试或保存不完整赛事。程序退出后任务结束，已保存的素材缓存供下次同步复用。

Replay 保持 0.2.10。验证结果见 [2.19.2 验证记录](VERIFICATION-2.19.2.md)。
