# ScoreDeck CS 2.15.0 · 自定义赛事流程

在 2.14.4 基础上重构赛事规则。Windows x64 便携包完整解压后运行 `ScoreDeck CS.exe`，确认左侧版本为 2.15.0。

## 建立赛事

1. 打开「赛事设置」或「赛段与流程」。新赛事的流程为空白。
2. 添加多个「小组赛」「瑞士轮」「Playoff」，或独立「单场对决」。左侧从上到下显示赛段顺序，可改名、上移、下移、删除。
3. 每个赛段在「参赛队伍」中选择直邀队。为晋级队预留的位置保持空白。
4. 在「赛制配置」设置组数、每组人数、赛制和默认 BO，应用模板生成比赛。
5. 在「晋级去向」设置循环赛每个名次、淘汰赛每场胜者和败者的去向：淘汰、结束及名次、后续赛段的具体入场位置、具体比赛的 A/B 位。
6. 可点击赛程图上的胜／负／名次端点，再点击目标入场位置或比赛 A/B 位完成连线。跨赛段连接可打开「查看完整流程」。一个位置只能接收一个来源；若位置已有直邀队、入场来源或晋级连线，需要先清空原来源。
7. 在「赛程与赛果」逐场修改 BO、日期、时间，录入大比分或地图与选手数据；将比赛状态改为「已完成」后自动推进。BO2 有效地图全部录入后沿用自动完赛规则。

## 支持的赛制

- 小组赛：自定义组数，各组独立设置人数和赛制；单循环、双循环、四队双败（GSL）。循环赛支持 BO1/2/3/5；GSL 每场支持 BO1/3/5。
- 单败：2—32 队的每一种人数，自动安排真实轮空；待定晋级队不会当作轮空。
- 八队双败：胜者组、败者组及总决赛；总决赛为单场系列赛，不自动重置。
- 瑞士轮：独立的 16 队模板，3 胜晋级／3 负淘汰，最多 5 轮，同战绩优先配对并避免重复交手；BU 为对手胜负差之和。最终名次可以逐个衔接后续赛段。BO1/3/5 可逐场修改。
- 附加单场对决：可在任意赛段外添加独立赛段，也可在已有赛段内添加比赛；BO1/3/5，胜负去向可编辑。附加比赛不计入循环赛积分。

## 排名与结果修正

小组支持「净胜小局优先」与「胜负关系优先」。赛事设置的全局规则会同步应用于现有各组，各组也可单独设置；该规则同时用于排名、晋级和 OBS。循环赛统计维持胜 3 分、BO2 平局 1 分；完全同分的最后确定性排序沿用队名规则。

上游赛果撤回、参赛队伍变化或瑞士轮配对依据变化时，下游失效比分、地图数据和 MVP 会清空，保留失效赛果快照用于核查。尚未完赛的循环赛排名不提前输送队伍。循环连线、重复占位、倒退到此前赛段、同队对阵自己会被拒绝。

「应用模板」会清除当前赛段比赛、比分和手工去向并重新生成；已开赛时会要求确认。只是改同分规则无需重建。删除目标位置前，请先修改指向该位置的上游路线。

## OBS 与导播

- 直播控制新增「输出赛段」「输出页码」。主对阵列表包含所选赛段的比赛。
- 完整赛程根据实际连线自动绘制；超过 16 队的单败赛程按两个半区分页展示，页码 1／2 切换。
- 小组积分每页最多 2 组；第三名榜只统计当前小组赛赛段中的循环赛小组；未来赛程每页 8 场。
- 自动轮播的每个节点都可以指定赛段和页码。
- 前瞻、入场动画、赛后 MVP 继续使用主对阵，保留原有素材和动画设置。
- 主输出、独立中场、RadarHUD、VoiceBridge 和导播悬浮窗继续沿用既有接口。RadarHUD 默认 23416，GSI 默认 31337，不占用 23415。

## 升级与归档

关闭旧程序后完整解压新版。可先在旧版「归档与恢复」导出完整 `.sdpack`，再在新版导入。完整包包含赛段、参赛位置、去向、赛果、队伍、素材与各模块设置；不含回放和录音缓存。

旧版固定赛制不会被静默重建，旧比赛继续可用。「建立空白流程」会保留队伍和素材，并保存旧赛事赛程快照；可从流程编辑器底部恢复旧赛程。恢复会替换当前流程，操作前应导出完整包。新格式不应交由 2.14.4 或更旧程序编辑。

## 源码与验证

- 赛事引擎：`server/tournament-flow.cjs`；浏览器使用同一份 `dist/assets/tournament-flow.js`。
- 流程界面：`ui/tournament-flow.js`；`npm run build:ui` 将其接入现有 React 程序。
- `npm test`：完整回归；`npm run test:flow`：新流程逻辑与 HTTP 持久化测试。
- 浏览器验证脚本：`scripts/qa-flow.cjs`、`scripts/qa-flow-outputs.cjs`，需要 Playwright 与 Chromium；可用 `CHROME_EXECUTABLE` 指定浏览器。
- 本次验证不包含真实 Windows 桌面、CS2/GOTV 或多人 TeamSpeak 实机操作。此前 2.14.4 审计中独立的 GSI 心跳、自动返回取消与 VoiceBridge 慢响应问题不属于本次赛事流程重构，不能由本版测试结果推断它们已修复。
