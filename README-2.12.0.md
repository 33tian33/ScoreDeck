# ScoreDeck CS 2.12.0

- 赞助商：仅在底部叠加图片，容器无背景、边框或阴影；不再为赞助栏挤压主画面。
- 中场：独立输出，不修改主直播场景。固定输出 /output/halftime；GSI 自动显隐 /output/halftime-auto。两个地址均在中场页面复制。
- 动态背景：中场外观支持导入 MP4 / WebM 或填写视频网址；静音循环播放，支持裁切、完整显示、拉伸。保留静态背景图片与透明背景设置。
- 中场 Replay 标签移除，展示位与比例不匹配的留白透明，OBS 输出画布之外的上下/左右留白也透明。
- 归档与恢复：只保留“导出完整包”和“导入完整包”。格式 .sdpack，直接在软件内导入，无需手动解压。

## 完整包

保存整个应用数据目录：全部赛事和界面设置、媒体目录（包括暂未使用的素材）、队标/头像/赞助商、入场/MVP/倒计时/中场/循环设置、端口、模块自启设置、RadarHUD 显示设置及记录、Replay 配置和本地回放、VoiceBridge API 配置/热词/队名/延迟/操作设置（回放与录音缓存从 2.12.1 起排除）。
2.12.1 不再收集 VoiceBridge 录音与 Replay 回放缓存；其设置及展示素材继续保存；赛事配置中的网址图片/视频会下载入包。缺失或无法下载的素材会明确报错。自定义网页和外部服务连接保留网址及配置，其远端服务仍需运行。

导出时暂停录制模块以获得一致快照，完成后恢复原先运行的模块。采用磁盘流式读写，取消原赛事 ZIP 的 500/512 MB 总量限制；需要足够磁盘空间。
导入前校验全部文件 SHA-256 与包结构，成功后重启桌面应用，恢复所有模块及端口设置。源包数据目录不同会重新映射素材路径。旧数据自动保留在原数据目录旁的 before-restore 目录。本机临时导播授权不沿用包内旧授权。

## 升级

完整解压到新目录运行 ScoreDeck CS.exe。迁移原设置时，先关闭程序，再把旧目录里的 ScoreDeck CS Portable Data 文件夹复制到新目录。更新后刷新 OBS 浏览器源一次。
保留官方 Electron 37.3.1 x64 完整运行时。Windows 10/11 x64；本次验证环境为 Linux + Chromium，未做 Windows/OBS 原生实机启动验证。
